# Claude.md

## Project Identity
This repository contains MubxAI Directory, a simple academic resource directory for HTU students.

## Product Goal
Build a course-based directory where each resource is attached to exactly one course.

## Core Rules
- Keep the first version simple.
- No AI unless explicitly requested.
- Support files and URLs.
- Keep the cost near zero.
- Make the mobile experience excellent.

## Development Priorities
1. Course search
2. Resource listing
3. Resource submission
4. Reporting and moderation
5. Authentication only if needed

## Data Philosophy
Use a strict course-to-resource relationship. Avoid nested categories or complex tagging systems.

## UI Philosophy
One primary task per screen. Search, browse, or upload — do not overload the interface.
